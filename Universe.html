Объект

3D‑карта
HTML + CSS + JS

Кликни по планете/узлу, чтобы открыть карточку. Колесо — зум, мышь — поворот. Все элементы автоматически «смотрят» на камеру, поэтому остаются круглыми.

Подсказки

• Тяни по пустому месту — поворот. Используй Shift при прокрутке для плавного зума.

• Нажми на объект, чтобы сфокусироваться. Кнопка «Сброс» вернёт исходный вид.

Трёхмерная сцена со звёздами и планетами. Управление мышью и колёсиком. Планеты биллбордятся к камере.
